使用 `.claude/skills/service-unit-test`。

目标：对用户指定的 Hify Java Service 方法执行单元测试工作流。

流程：
1. 先读被测 Service 类，再读依赖 DTO、ErrorCode、BizException、已有测试。
2. 先输出测试计划，不写代码。计划必须包含执行路径树、边界条件表、P0/P1/P2 场景表。
3. 在写代码前做技术确认：mock 方式、AssertJ、Bean Validation 场景、错误码是否存在、Service 测试和 DTO 约束测试是否拆分。
4. 用户确认后再写测试代码。
5. 先跑目标测试，失败后判断是测试写错还是实现有 bug；必要时补最小生产实现。
6. 最后跑模块范围测试并汇报结果。

用户参数：
`$ARGUMENTS`
