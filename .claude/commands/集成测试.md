使用 `.claude/skills/hify-integration-test`。

目标：对用户指定的 Hify 模块、接口或核心链路执行集成测试工作流。

流程：
1. 先读 `CLAUDE.md` 核心链路和风险地图，再读 mock profile / H2 / mock schema 配置。
2. 先输出 P0/P1/P2 测试清单，不写代码。清单表格必须包含 IT 编号、场景、验证点、优先级、依赖准备、mock 策略。
3. 写代码前确认技术基础：mock profile、H2、MockMvc、测试基类、`@Sql` 数据、外部依赖 mock 边界。
4. 从最简单场景开始，一个场景跑通后再写下一个。
5. 每个测试方法用独立 `@Sql` 数据；同步接口可用 `@Transactional + @Rollback`，SSE/异步测试用 isolated `@Sql` 插入和清理。
6. 外部 API、LLM、MCP Server、pgvector 等 mock 掉；Hify 自身 Controller/Service/Mapper/DB 链路不 mock。
7. 已知 bug 必须先写失败测试并运行；确认红灯后再修最小生产代码，让测试变绿。
8. 最后跑相关测试类或核心回归组合并汇报结果。

用户参数：
`$ARGUMENTS`
